`mend` is one command-line tool that applies the edits AI models write — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits — to a tree of files, matching target lines at three tiers (exact, rstrip, trim), with all-or-nothing application and exact usage/parse/no-match reporting per SPEC.md. 100/100 public practice checks.

## Run it

```sh
node main.ts [options] [PATCH]   # apply a patch to a tree of files
node check.ts practice.json      # run the 100 public practice checks
```
